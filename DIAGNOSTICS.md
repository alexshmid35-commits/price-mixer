# Диагностический bundle Price Mixer

Инструмент создаёт небольшой ZIP для первичного разбора проблем:

```bash
python deploy/diagnostics.py /tmp/price-mixer-diagnostics.zip
```

Существующий файл назначения не перезаписывается.

Архив содержит `diagnostics.json` и краткий `README.txt`. В JSON входят:

- версия приложения, Python и основных зависимостей;
- только разрешённые несекретные параметры production-профиля;
- агрегированные количества и размеры runtime-каталогов;
- свободное место на диске;
- read-only `PRAGMA quick_check`, версия схемы и количество таблиц SQLite.

Инструмент намеренно не включает:

- значения переменных окружения;
- `.env`, credentials и API-токены;
- содержимое логов;
- содержимое state JSON;
- строки SQLite;
- пути пользователя, имена upload-сессий и имена runtime-файлов.

Перед передачей архива третьей стороне всё равно рекомендуется открыть
`diagnostics.json` и убедиться, что его системные метаданные допустимы для
конкретного случая.
